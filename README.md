# Digital Crime Scene — SEASAW

Interactive beginner-friendly cyber-forensics investigation built with React, JSX, JavaScript and Vite.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (the default port is 3000).

## Production build
```bash
npm run build
npm run preview
```

## Notes
- The application source is JavaScript/JSX only.
- Vite configuration is `vite.config.js`.
- Images are imported from local assets so Vite includes them in production builds.
- The investigation uses fictional data and does not connect to real accounts or systems.
